# Dziennik podróży

Prosta aplikacja (PWA) do nagrywania fragmentów raportu z podróży: dźwięk + transkrypcja na żywo (PL/ES/EN),
automatyczna lokalizacja i pogoda, do tego zdjęcia, dokumenty i notatki. Dane zostają na urządzeniu.

Uruchomienie lokalne: `python3 -m http.server 8000` → http://localhost:8000.
Hosting: GitHub Pages (gałąź `main`, katalog główny). Szczegóły w [CLAUDE.md](CLAUDE.md).
